#### 3.1 修复抢单并发问题
**文件**: `ErrandOrderServiceImpl.java:124-196`

**当前问题**:
```java
// 锁内再次查询订单(可能读到旧数据)
BusErrandOrderEntity order = this.getById(orderId);
// 乐观锁更新后又执行了一次updateById,破坏原子性
this.updateById(order);
```

**修复方案**:
```java
@Transactional(rollbackFor = Exception.class)
public void acceptOrder(Long orderId) {
    String lockKey = "lock:errand:order:" + orderId;
    try {
        redisCache.tryLock(lockKey, 10, TimeUnit.SECONDS);
        // 直接使用乐观锁更新,无需先查询
        int rows = errandOrderMapper.acceptOrderAtomic(orderId, runnerId, ...);
        if (rows == 0) {
            throw new ServiceException("抢单失败,订单已被接单");
        }
    } finally {
        redisCache.unlock(lockKey);
    }
}
```

#### 3.3 修复余额并发问题
**文件**: `BusStudentServiceImpl.java:90-97`

**修复方案**:
```java
@Transactional(rollbackFor = Exception.class)
public boolean updateBalance(Long studentId, BigDecimal amount) {
    String lockKey = "lock:student:balance:" + studentId;
    try {
        redisCache.tryLock(lockKey, 5, TimeUnit.SECONDS);

        // 检查余额
        BusStudentEntity student = getById(studentId);
        if (student.getBalance().compareTo(amount.abs()) < 0) {
            throw new ServiceException("余额不足");
        }

        // 使用乐观锁更新
        int rows = busStudentMapper.updateBalanceWithVersion(
            studentId, amount, student.getVersion()
        );
        return rows > 0;
    } finally {
        redisCache.unlock(lockKey);
    }
}
```

```java

@Component
public class AuthenticationCleanupFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) {
        try {
            filterChain.doFilter(request, response);
        } finally {
            AuthenticationContextHolder.clearContext();  // 清理ThreadLocal
        }
    }
}
```

```java
firstLevelComments.forEach(comment -> {
    List<ForumCommentVO> replies = commentMapper.selectSecondLevelComments(comment.getCommentId());
    comment.setReplies(replies);

```

**修复方案**:
```java
// 使用批量查询
List<Long> commentIds = firstLevelComments.stream()
    .map(Comment::getCommentId)
    .collect(Collectors.toList());

Map<Long, List<ForumCommentVO>> repliesMap = commentMapper
    .selectSecondLevelBatch(commentIds)
    .stream()
    .collect(Collectors.groupingBy(ForumCommentVO::getParentId));

});
```
